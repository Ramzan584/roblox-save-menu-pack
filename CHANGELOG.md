# Журнал изменений

## 2026-11-15 — Save Lobby Blender Bridge v1.0

- Направление: инструменты Codex для Blender. Импорт блоков Save Lobby,
  отдельный FBX на модель, применённый масштаб, сцена и рендер-превью.
- Реальный запуск Blender 5.1.1: обратный импорт 6 FBX с проверкой габаритов
  и числа деталей. Два теста Python. Импорт в Roblox ещё не проверен.

## 2026-11-12 — Save Lobby Kit v1.0

Направление: оригинальные модели Roblox Studio.

- Шесть моделей мебели и окружения из 28 закреплённых деталей, готовая
  XML-модель с демонстрационной расстановкой.
- Генератор с двумя палитрами, масштабом 0.25–4 и отчётом SHA-256.
- Пять автоматических тестов, инструкция импорта и пример зоны чекпоинтов.
- Только оригинальная геометрия, CC0. Импорт в Studio пока не проверен.

## 2026-11-09 — Studio XML Sync v1.0.0

Направление: инструменты Codex для Roblox Studio.

- Добавлен офлайн CLI для проверки и переноса Luau-исходников в XML-модель
  и демоместо с сохранением клиентских/серверных путей.
- Добавлены предварительный просмотр расхождений, JSON-отчёт с SHA-256,
  сборка в новую папку, проверка путей, классов, дубликатов и конфликтов копий.
- Добавлены 15 автоматических регрессионных тестов, пример изменения меню,
  инструкции импорта в Studio и отчёт о реально выполненных проверках.
- Исходная игровая логика, модели и ZIP v0.1.0 не изменены.

## 2026-11-04 — исходный пак v0.1.0

Система сохранений и меню, 14 скриптов Luau, демоместо, импортируемая модель
и документация RU/EN. Подробности исходных проверок — VALIDATION.txt.
