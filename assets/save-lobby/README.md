# Save Lobby Kit v1.0 — оригинальная мебель для зоны сохранения

Шесть моделей из обычных закреплённых Parts: две скамьи, две клумбы,
арка и декоративная информационная стойка. Набор подходит для оформления
площадки перед меню или чекпоинтами. Встроенных скриптов, текстур, сетевых
запросов и сторонних ассетов нет. Все формы созданы специально для этого
набора; CC0 по корневому LICENSE.txt.

## Установка и демонстрация в Studio

1. Скачай репозиторий через Code → Download ZIP и распакуй.
2. В отдельной тестовой игре импортируй `generated/SaveLobbyKit.rbxmx`
   через Insert from File в Explorer. Помести модель SaveLobbyKit в Workspace.
3. Шесть вложенных Model уже расставлены сеткой 3 × 2 с шагом 16 studs.
   Это демонстрационная расстановка, которую можно осмотреть целиком.
4. Выбери нужную вложенную модель и перенеси инструментом Move. Нижняя
   граница объектов — Y=0; перемещай весь Model, чтобы сохранить соединения.
5. Пример применения: поставь Gateway перед зоной чекпоинтов, BenchShort
   слева, PlanterSquare справа, Kiosk рядом со входом. Дублируй Model для
   повторного использования. Не переименовывай существующие игровые чекпоинты.
6. Нажми Play: пройди под аркой, проверь столкновения с мебелью и отсутствие
   новых ошибок Output. Скамьи декоративные: автоматического сидения нет.
   Стойка не сохраняет прогресс и не вызывает меню; для этого используется
   существующая система сохранений пака. Эти модели не заменяют её Parts.

У деталей Anchored=true, CanTouch=false; декоративная листва и цветные
маркеры не имеют столкновений. Основа мебели и колонны имеют столкновения.
Если мебель мешает проходу, передвинь её либо измени CanCollide в Studio.

## Состав и размеры при scale=1

| Model | Деталей | Габариты, studs (X × Y × Z) |
|---|---:|---|
| BenchShort | 4 | 6 × 3.8 × 2 |
| BenchLong | 4 | 10 × 3.8 × 2 |
| PlanterSquare | 4 | 3 × 3.1 × 3 |
| PlanterWide | 4 | 6 × 3.1 × 3 |
| Gateway | 6 | 11 × 9 × 2.5 |
| Kiosk | 6 | 3 × 4.8 × 2.5 |

Gateway имеет проход шириной 8 и высотой 8 studs до нижней грани перемычки.
Размеры задаются непосредственно в studs, без преобразований единиц Blender.

## Воспроизводимая генерация

Python 3.10+, только стандартная библиотека. Проверено Windows / Python
3.12.14. В корне репозитория:

```console
python assets/save-lobby/generate.py --output builds/lobby-forest
python assets/save-lobby/generate.py --output builds/lobby-coast --scale 1.5 --palette coast
python -m unittest discover -s assets/save-lobby -v
```

Палитры: forest и coast. Масштаб: 0.25–4, применяется к геометрии и шагу
демонстрационной сетки. Для создания варианта выбери новую папку: существующая
не перезаписывается. Источник истины — generate.py; для постоянных изменений
размеров редактируй функцию furniture и создай новую сборку.

Файлы:

- `generate.py`: параметры деталей, XML-экспорт и отчёт SHA-256.
- `test_generate.py`: проверки структуры, геометрии, масштабов и записи.
- `generated/SaveLobbyKit.rbxmx`: готовый набор и демонстрационная расстановка.
- `generated/manifest.json`: палитра, масштаб, число деталей, контрольная сумма.
- `VALIDATION.md`: выполненные проверки и ограничения.

## Совместимость и ограничения

Формат — текстовый Roblox XML v4 с обычными Model и Part. Сторонние плагины
не нужны. Импорт движком в этой среде не проверен; гарантированную минимальную
версию Roblox Studio не заявляем. При изменении XML-формата импорт нужно
перепроверить. Сгенерированный XML проверен стандартным парсером Python.
Материалы по умолчанию, без сложных мешей, LOD, текстур и пользовательских UV.
Внешний вид зависит от освещения игры. Масштабирование не учитывает размеры
аватара: особенно маленькие варианты проверяй в режиме Play.

Это файловый генератор для Roblox; Blender не требуется. Управление открытым
Roblox Studio или Blender не настроено и не заявляется. Для интеграции с Codex
достаточно редактировать generate.py, выполнить команды выше и импортировать
полученную модель вручную. Секреты и локальный сервер не нужны.
