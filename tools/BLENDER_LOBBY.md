# Save Lobby Blender Bridge v1.0

Переносит оригинальные блоковые модели Save Lobby Kit в редактируемую сцену
Blender и отдельные FBX. Полезно для дальнейшей ручной доработки мебели,
экспорта в Roblox и проверки, что единицы не изменились при экспорте.
CC0, сторонних ассетов нет. Требуется Blender 5.1 с FBX import/export;
фактически проверен Blender 5.1.1 на Windows. Другие версии не проверены.

## Запуск и пример

Из корня распакованного репозитория в PowerShell:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --factory-startup --python-exit-code 1 --python tools/blender_lobby.py -- --output builds/blender-lobby
```

Выбери новую папку назначения. Открытая пользовательская сцена не затрагивается:
команда запускает отдельный процесс с заводской сценой. Сам скрипт очищает сцену
в своём процессе, поэтому не запускай его через Text Editor в рабочей сцене.
Это проверенный пакетный способ работы Codex с Blender через CLI, без мостов
управления и открытых портов. Управление открытым окном не настраивалось.

Параметры после `--`: `--source путь.rbxmx`, `--output новая-папка`,
`--meters-per-stud 0.28`. Последнее — явное соглашение этого инструмента;
менять можно в пределах 0.01–10. Roblox X,Y,Z переходят в Blender X,-Z,Y.
Размеры мешей применены, scale=(1,1,1). Каждый FBX центрирован по горизонтали
и стоит нижней границей на нуле. В .blend объекты разнесены для осмотра.

Пример: открой созданный SaveLobby.blend, выбери BenchLong_Seat, измени форму
в Edit Mode. Экспортируй только детали одной модели, сохраняя единицы и оси
из report.json. Генератор сам экспортирует исходный набор, ручные изменения
в сцене он не читает. Для новых исходников сначала пересобери Save Lobby Kit.

Результат: шесть `.fbx`, `SaveLobby.blend`, настоящий рендер `preview.png`,
`report.json` с версией Blender, единицами, габаритами и результатом обратного
импорта. Проверка габаритов и числа объектов выполняется после каждого
FBX-экспорта; при несовпадении процесс завершается ошибкой.

## Проверка в Roblox Studio

В отдельном тестовом месте открой 3D Importer и выбери, например, BenchLong.fbx.
До подтверждения импорта проверь габариты: при стандартном коэффициенте
скамья должна соответствовать 10 × 3.8 × 2 studs исходного набора. При необходимости
настрой импортные единицы по этому эталону; коэффициент импортера здесь не
проверялся. Поставь модель в Workspace, закрепи MeshParts, проверь коллизии
и цвета, затем Play. FBX не переносит Anchored/CanTouch/CanCollide Roblox.
Готовый .rbxmx из assets/save-lobby предпочтителен, если доработка в Blender
не требуется. Новых клиентских или серверных скриптов в этом мосте нет.

## Файлы и ограничения

- `blender_lobby.py`: строгий импорт осевых блоков, экспорт, проверка и рендер.
- `test_blender_lobby.py`: тесты единиц, осей и числа деталей без Blender.
- `blender-lobby-report.json`: фактический отчёт выполненного запуска.
- Исходник: `assets/save-lobby/generated/SaveLobbyKit.rbxmx`.

Произвольные Roblox-модели, повёрнутые Parts, сферы, вложенные скрипты,
MeshParts, текстуры и анимация не поддерживаются. Используй доверенный
исходник пака. При ошибке экспорта папка может содержать частичные результаты:
проверяй успешное завершение и report.json. Blender 6.0 не заявлен совместимым:
5.1 предупреждает о будущем удалении Material.use_nodes.

Проверки 2026-11-15: Blender 5.1.1 завершил генерацию и рендер с кодом 0;
6 FBX импортированы обратно, 28 объектов, габариты совпали с допуском .001 м.
Превью осмотрено. Два теста Python прошли. Поиск типовых токенов и приватных
ключей в файлах публикации не дал совпадений. Реальный импорт в Roblox не
выполнялся. Бинарные результаты сохранены локально; GitHub содержит код и отчёт,
из которых результат воспроизводится указанной командой.
